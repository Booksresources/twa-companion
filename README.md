# Text and Web Analytics: Methods, Tools, and Applications with Python
## Companion files

This archive contains the code listings, datasets, simulators, and demonstration website used in the book.

### Contents

| Folder | Contents |
|---|---|
| `code/chapter_NN/` | Every code listing in the book, named `listing_CC_NN.py` after its listing number (for example, `listing_07_02.py` is Listing 7.2). Shell commands use `.sh`. |
| `code/front_matter/`, `code/appendices/` | Setup commands from the front matter and Appendix A. |
| `data/` | Synthetic datasets: `reviews.json` (Chapters 17, 18, and Section 8.7), `jobs.json` (Chapter 17), `posts.json` (Chapter 14), `access.log` (Chapters 13 and 17), and `feedback_raw.csv` (Section 2.7). |
| `simulators/` | The scripts that generated the synthetic datasets. Rerun them to recreate or vary the data. |
| `demo_site/` | The demonstration library website crawled in Chapter 12. |
| `requirements.txt` | Library versions used to test the listings (see Appendix A). |

### Getting started

1. Create and activate a virtual environment, then install the requirements (Appendix A):
   `pip install -r requirements.txt`
2. Download the NLTK data and the spaCy model:
   `python -c "import nltk; nltk.download(['punkt_tab','stopwords','wordnet','brown','reuters','movie_reviews','udhr','vader_lexicon'])"`
   `python -m spacy download en_core_web_sm`
3. Copy the files from `data/` into the folder where you run the listings, or start your notebook in the `data/` folder.

### Important notes

* **Run listings in order.** Within a chapter, later listings often use objects created by earlier ones (for example, Listing 7.3 uses the model trained in Listing 7.2). The simplest approach is to paste each chapter's listings into one notebook and run them from top to bottom.
* **Cross-chapter dependencies.** A few listings reuse earlier results: Listing 15.2 uses the Word2Vec model from Listing 5.6, Listing 18.4 loads the model saved in Listing 7.7, and Listings 13.x and 17.8 use the bookstore log data.
* **The demonstration website (Chapter 12).** In a terminal, go to `demo_site/` and run `python -m http.server 8766`, then run the Chapter 12 listings in another window.
* **Web collection (Chapter 3).** Listings 3.5 and 3.11 use the public practice site books.toscrape.com, which is designed for learning web scraping. Keep the polite delays in place.
* **Listings that need downloads, a GPU, or an API key** (Listings 3.6, 3.7, 5.8, 8.4, 9.4, 15.5, 15.6, 16.2, and the dashboard in 18.3) are marked in the book. Run them in a cloud notebook if your computer is limited.
* **Results may differ slightly** with other library versions or random seeds.

### Synthetic data

The reviews, job postings, social media posts, and web logs are synthetic, generated by the scripts in `simulators/`. All products, companies, people, and accounts in them are fictional. The Reuters-21578, Brown, Movie Review, and UDHR corpora are distributed with NLTK under their own terms.
